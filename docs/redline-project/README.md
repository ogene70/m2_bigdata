# Redline project

Exploration of big-data use cases for the *Redline* project. Each idea describes a goal, the analysis to perform, and the hardware/tools required.

## Ideas

| Idea | Description | Required tools |
|---|---|---|
| Consumption tracker | Advise the user on vehicle consumption | Drone + OBDII reader |
| The visualiser | Shot/analysis of camera footage | Drone |
| The maestro | Assistant for pianists, helping beautify their playing | Microphone + piano |

See [Ideas](/redline-project/ideas.md) for details.
