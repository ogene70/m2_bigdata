Bigdata is an informatic domain that established how massive data are managed
in organisations.

## Where it's come from ?

Historicaly it's come from speed issues in data delivery in compagny like Google with the HDFS model based on MapReduce technology.
Because of their massive data traitement they reached a material edge that change their way to manage data.
But what are the map reduce edges ?**
So, to understand that it's important to understand how mapReduce workflow run.
first of all the relevent datas are filtered/selected to be used, then this filtering creat a new piece of data without changing the source. But this process works on disc memory wich influence data treatment time.

Following that, a new way to compute direcly in fast memery was born. This new approach permit now to proceed faster.
