# Tracability

Tracability is the action to monitor flux in systems.
In BigData this is a sensible point that allaws to manage data transmisson and quality. This is also a lever for the system evolution.

## What are it's purposes ?

Tracability has several puprose for a system:

- Problem solving/detection.
- Data quality trougth data flux visibility.

All of thoses point trougth data flux visibility.

## How is it set ?

To allaw tracability on your systems you must follow this following workflow:
Define what points you want to trace in the system -> retrives datas to follow thoses metrics -> display them in human readable version.
